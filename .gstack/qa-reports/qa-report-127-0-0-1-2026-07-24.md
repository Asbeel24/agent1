## Recording and audio

- Start and stop cues use 90% dry / 10% wet reverb.
- Output peaks remain below clipping (`-5.5 dB` start, `-6.4 dB` stop).
- Recording starts from the single semantic button, exposes the timer, and returns to idle after stopping.
- Stopping clears microphone/voice state, timer UI, and microphone CSS level state.
- The particle orb is no longer a nested `role="button"` around the real recording button.

## Responsive and accessibility regression

Crossing from mobile to desktop previously left `translate(-50%, -50%)` on `.orb-stage`, shifting the orb to the upper-left. The breakpoint listener now clears GSAP-owned positioning state, and the initial cursor listener is removed correctly on cleanup.

The mobile navigation also now has stable accessible names such as `翻译 01`, rather than duplicated pseudo-content such as `翻译翻译`.

## Interface alignment

- Task states now include `queued`, `planning`, `pending`, `retrying`, and canonical terminal state `succeeded`.
- The undocumented `completed` payload state was removed; `server.task.completed` remains the event name.
- `{ type, data }` is documented as the frontend's canonical internal representation, not an assumed WebSocket envelope.
- Server events now receive event-specific payload validation instead of only checking that `data` is an object.
- Malformed task and translation event probes are rejected.
