## ISSUE-001 — Recording sound cues

The supplied 0.261-second MP3 cues are now preloaded and played as one-shot feedback:

- `record-start.mp3` when recording is started
- `record-stop.mp3` when recording is stopped or an active recording is ended by changing scenes

The audio elements are reset before replay, cleaned up on unmount, and tolerate browser autoplay rejection without interrupting recording.

## ISSUE-002 — Mobile language controls

The former mobile layout compressed the language controls into a narrow strip between navigation and the scene title. On tablets it pushed language codes against the right edge.

The responsive control is now a centered, full-width language panel with:

- stable source / swap / target columns
- larger touch targets
- contained language labels
- no horizontal overflow
- extra separation from the translation scene title
- navigation width that no longer collides with the BicaMind wordmark on 320px screens
